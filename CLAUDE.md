# CLAUDE.md

FastAPI backend boilerplate: async SQLAlchemy 2 (psycopg) + Alembic, typed error envelope, JWT auth, an SSE streaming example. Python 3.12+, managed with `uv`.

## Commands

```bash
uv sync
cp .env.example .env                                  # then set db_uri / secret_key
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --port 8000      # API under root_path (/api/v1)

# Checks — run in this order
uv run ruff check .
uv run ruff format --check .
uv run mypy                                           # strict, over app/
uv run pytest                                         # offline: no DB needed

uv run alembic revision --autogenerate -m "describe change"
```

Add dependencies with `uv add` / `uv add --dev`, never by editing `pyproject.toml` by hand.

## Layout

| Path | Role |
|---|---|
| `app/main.py` | Entrypoint: logging first, then `create_app(...)` + `api_router`. Lifespan waits for the DB. |
| `app/asgi.py` | `create_app` — error handlers, middleware order, `/health/live` + `/health/ready`. |
| `app/config.py` | `Settings`; the only place configuration is read. |
| `app/errors.py` | `AppError` and every typed error. |
| `app/exception_handlers.py` | Turns every exception path into the envelope. |
| `app/database.py` | Engine, `SessionFactory`, `Base` (constraint naming). |
| `app/auth.py` | Password hashing and access tokens — no HTTP. |
| `app/api/` | One module per resource + `router.py` + `dependencies.py` (`DbSession`, `CurrentUser`, `StreamingUser`). |
| `app/services/` | Business rules. |
| `app/models/` · `app/schemas/` | ORM tables · request/response models. |
| `app/common/` | Small helpers with no domain (`paginate`, `NewPassword`). |

## Conventions

- **Errors.** Every error response is `{"error": {"type", "message", "details"?}}`. Services raise `AppError` subclasses from `app/errors.py`; endpoints do not catch them. `error_type` is the stable client contract; `message` is an English fallback. Add one error type per distinct thing the caller would *do next*.
- **Transactions.** Services `flush`, endpoints `commit` once at the end, so a refusal anywhere rolls the whole request back. Rows stay readable after commit (`expire_on_commit=False`), and a model with database-generated columns sets `__mapper_args__ = {"eager_defaults": True}` to read them back via `RETURNING` — an async session cannot lazy-load (see `User`).
- **Endpoints** declare their response model as the return annotation (no `response_model=`), take parameters as `Annotated[..., Query()/Depends()]`, spell out a real path on every route (never `""` under a router prefix), name resources as plural nouns (`/users`; the caller is `/me`), answer `201` for a create and `204` for no body, and keep plain reads inline; anything with a rule goes to `app/services/`. `app/api/user.py` is the reference slice to copy.
- **Lists** use `paginate()` and `PaginatedResponse`; build the filter once and apply it to both the count and the row query.
- **PATCH schemas** default every field to `None` meaning "not sent", apply `model_dump(exclude_unset=True)`, and refuse an explicit `null` for a NOT NULL column (see `UserUpdate`).
- **Database defaults** (`server_default`) are the single source of a column's default; the migration states the same. Read every autogenerated migration before committing it, and never edit one that has been applied anywhere.
- **Constraint violations** a user can cause are mapped to a typed error by constraint *name* (see `services/user.register`); any other `IntegrityError` falls through to the generic 409.
- **Auth.** Every token refusal raises the same `UnauthenticatedError` (401 + `WWW-Authenticate: Bearer`). Bump `token_version` (`revoke_tokens`) to sign an account out everywhere.
- **Streaming (SSE).** `app/api/chat.py` is the reference: `response_class=EventSourceResponse`, the endpoint `yield`s `ServerSentEvent`s, and the content comes from an async generator in `app/services/`. A streaming endpoint takes `StreamingUser`, never `CurrentUser`/`DbSession`, which would pin a pooled connection for the stream's lifetime. Once the stream has started the status line is gone, so a failure is sent as a final `error` event (`{type, message}`, an `AppError` keeping its `error_type`), not raised.
- **Logging.** Use stdlib `logging.getLogger(__name__)`; loguru receives it. Sinks run with `diagnose=False` so tracebacks never print local variables (passwords, tokens).
- **A second ASGI app** is another `create_app(...)` call in its own `*_main.py`, never a hand-built `FastAPI()`.

## Adding a resource

1. Model in `app/models/<name>.py`, re-exported from `app/models/__init__.py`.
2. Schemas in `app/schemas/<name>.py`.
3. Rules in `app/services/<name>.py`; new error kinds in `app/errors.py`.
4. Endpoints in `app/api/<name>.py`, mounted in `app/api/router.py`.
5. `uv run alembic revision --autogenerate -m "..."`, then review the generated file.
